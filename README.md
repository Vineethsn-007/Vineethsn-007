## 🚀 Featured Projects

### 🛡️ Multi-Agent IoT Intrusion Detection and Resolution System
> Final-year project (VTU 2026-27). Five cooperating LangGraph agents detect, attribute and respond to attacks on IoT devices.

- Agents profile device behaviour, detect anomalies (Isolation Forest), attribute attacks (Random Forest), plan mitigations and produce a plain-language severity report
- Attacks mapped to **MITRE ATT&CK**; SHAP cut **115 N-BaIoT features down to 15**
- Reduced detector flagged every sampled attack row at a **5.80% false-positive rate** (device-holdout split)
- Live **ESP32 + DHT11** telemetry, Scapy packet-level feature extraction and a web dashboard

`Python` `LangGraph` `scikit-learn` `SHAP` `ESP32` `Scapy`
